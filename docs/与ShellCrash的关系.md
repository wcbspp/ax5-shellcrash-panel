# 面板与 ShellCrash

ShellCrash 提供工具菜单、订阅获取与转换、内核及数据库下载源。sing-box / Mihomo 处理代理流量；面板通过 AX5 适配层发起操作、校验结果并显示状态。

适配层沿用小米管理页的登录权限，按需执行系统命令，复用现有 LuCI 服务。

| 操作 | 调用关系 |
| --- | --- |
| 启动、停止、重启 | 面板 → ShellCrash start.sh → AX5 cli.sh → 同一个 procd 服务 |
| 直接下载订阅 | ShellCrash get_core_config → 临时候选 → 面板整理节点 → 内核校验 → 保存并加载 |
| 转换订阅 | 所选 ShellCrash 转换服务 → 临时候选 → 面板整理节点 → 内核校验 → 保存并加载 |
| 内核、域名库下载 | ShellCrash 工具源 → 适配层校验 → 替换、备份与回退 |
| 节点、连接、延迟 | 当前内核的管理接口 |
| 日志、内存、ZeroTier | 系统状态与监控记录 |

订阅下载在独立临时目录进行。直接下载失败可尝试面板兼容下载；转换下载可选择失败轮询。转换服务先接受不含订阅地址的接口预检，通过后才接收订阅。下载成功后仍须通过配置校验，获取方式不会决定代理流量的分流规则。

终端与页面操作共用启动入口。AX5 适配补丁调整了工具的启动和更新函数，原始 1.9.4release 安装包单独保存在 vendor 中。

## 开机与守护

开机启动遵循 ShellCrash 的开关设置。配置页可选择：

- 系统守护：由 procd 监督代理进程。
- 每分钟检测：复用现有采样任务，发现代理退出后尝试恢复，并关闭 procd 自动拉起。

两种守护互斥。手动停止、配置更新及已有操作锁时，每分钟检测不会拉起代理；连续失败会延长重试间隔。首页显示当前方式、执行方和启动来源。

内存保护、安全清理、备份回退与异常记录由适配层保留。主动停止不计为异常恢复。

K2P 使用 Padavan 启动适配和 ShellCrash 原生每分钟守护，与 AX5 的 procd 环境不同，启动脚本不能互换。
