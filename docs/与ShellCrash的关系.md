# 面板与 ShellCrash

ShellCrash 提供工具菜单、订阅获取与转换、内核及数据库的下载源。sing-box / mihomo 实际处理代理流量；面板显示状态并发起操作。

AX5 适配层仍是必要组件，并非只有 HTML 页面：小米原厂 LuCI 没有代理服务的管理接口，浏览器也无法直接执行系统命令。适配层复用路由器登录权限，按需执行操作，不增加一套常驻网页服务器。

| 操作 | 调用关系 |
| --- | --- |
| 启动、停止、重启 | 面板 → ShellCrash start.sh → AX5 cli.sh → 同一 procd 服务 |
| 订阅读取／转换 | 面板 → 官方 starts/core_config.sh 的 get_core_config → 临时候选 → 面板分组及内核校验 → 保存 |
| 内核、域名数据库下载 | 复用 ShellCrash 的 get_bin 和安装源；适配层校验并控制替换、备份、回退 |
| 节点、连接、延迟 | 当前代理内核的管理接口 |
| 内存、日志、ZeroTier | 按需读取系统状态；一分钟采样并执行阈值清理 |

官方订阅函数在独立临时目录工作，不能直接覆盖运行配置。直接读取失败可回到原读取方式；转换使用工具当前选择的服务，不尝试另一个转换服务器。转换结果仍须通过当前内核检查，工具能获取某种格式，不代表跨内核适配支持所有协议。

本项目修改过工具的启动和更新入口，使终端与页面管理同一个服务。不能把适配后的 ShellCrash 称为完全未经修改的官方运行方式。安装包里的原始 1.9.4release 压缩包保持不变，适配补丁单独提供。

内存保护、安全清理、备份回退、异常记录和监控继续保留。操作结束后核对进程和内核接口；命令退出码为零不足以判定服务运行正常。主动停止不会计为异常。

K2P 采用 Padavan 的管理入口和启动适配；同样复用 ShellCrash 的订阅函数，保留其低内存保护和 Storage 持久化流程。不能直接将 AX5 的启动脚本复制给 K2P。
