# 数据库与分流

当前配置使用国内 IPv4 网段和国内域名规则集。两者分别决定国内 IP、国内域名直连；DNS 的 Mix 模式还会让国内域名及用户例外名单返回真实地址。例外名单只改变 DNS 返回值，流量是否代理仍由分流规则决定。

| 文件 | mihomo | sing-box | 当前用途 |
| --- | --- | --- | --- |
| 国内 IPv4 文本网段 | 转成 IP-CIDR | 转成 ip_cidr | 国内 IP 直连 |
| cn.mrs | 使用 | 不使用 | 国内域名直连、国内 DNS |
| cn.srs | 不使用 | 使用 | 国内域名直连、国内 DNS |
| Country.mmdb / GeoIP 数据库 | 当前未引用 | 当前未引用 | 当前不需要 |
| GeoSite.dat / 通用分类库 | 当前未引用 | 当前未引用 | 当前不需要 |

MRS 和 SRS 是不同格式，不能改扩展名互用。切换内核时会引用对应的国内域名文件。两份规则的更新日期和内容可能不同，不能保证分类逐条一致。

## 在面板更新

“更新国内 IP 规则”只更新 IPv4 网段。“更新当前域名库”调用 ShellCrash 自带的 get_bin 下载当前内核适用的 MRS 或 SRS 包，只取 cn.mrs 或 cn.srs，不安装其他分类。

域名库更新会检查剩余空间、校验生成配置，成功后替换文件并恢复服务；实际替换时代理会短暂停止。失败恢复旧文件和服务。文件相同则不重启；检查时间保存在内存中，避免每次检查写闪存。成功替换后尝试同步私有配置备份，云端失败单独提示，已生效的本地文件保留。

规则页展示当前文件及哈希摘要。哈希用于识别内容，不代表官方发布日期。2026-10-10 两个内核都执行了真实工具源更新检查，下载文件与已有文件相同，因此验证了“相同文件不重启”。替换、校验失败、恢复失败和云端失败分支另用隔离测试验证。

## ShellCrash 数据库菜单

CN-IP 下载的新文本不会自动改写本项目生成的配置，请使用面板 IP 更新按钮。CN-IPv6 当前未使用。GeoIP_cn、GeoSite 以及 MRS/SRS 整包中的其他分类，只有配置显式引用才生效。工具的“清理数据库”可能删除正在引用的 cn 文件并导致启动失败，不能把它当作清理日志。

本次在没有 GeoSite.dat、Country.mmdb 和通用 GeoIP/GeoSite 文件的条件下，验证了两个内核的启动、国内直连、国外代理、Fake IP 和真实地址例外。这里仍保留 cn.mrs、cn.srs 和国内 IP 规则，不能将它们一起删除。若以后增加游戏、广告等分类规则，需要另行提供对应的规则集。

## 空间和完整 GeoSite

已备份并移除未被运行环境使用的持久 locale-archive，压缩历史日志。UBIFS 压缩使实际释放空间约为 1.8 MB，并非文件逻辑大小的总和。保留了 ZeroTier 的运行库和身份；更新 ZeroTier 后还需验证重启。

完整 GeoSite 文件约 4.1 MB，当前 mihomo 安装状态的 /data 余量约 2 MB，无法安全容纳。即使腾出空间，完整分类库还有内存开销。当前只需要国内分类，保留单独 cn.mrs / cn.srs 更适合这台设备；本项目没有切换到完整 GeoSite。

## DNS 核对

两个内核均验证 google.com 返回 198.18.0.0/15 中的 Fake IP，www.openai.com、www.apple.com、stun.l.google.com、www.mi.com 及国内域名返回真实地址。客户端旧缓存或绕过路由器的加密 DNS 会影响观测，应确认查询的是路由器 DNS。IPv6 未启用，以上验证为 A 记录。
