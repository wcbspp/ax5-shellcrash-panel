# 当前配置使用哪些数据库

本页针对本项目生成的 AX5 配置。ShellCrash 可以下载很多数据库，但只有配置引用的文件才参与分流。

| 工具菜单 | 当前用途 |
| --- | --- |
| 1 CN-IP | 下载 cn_ip.txt；本项目面板把国内 IPv4 网段写入配置，不会自动读取这个新文件。更新请用规则页按钮。 |
| 2 CN-IPv6 | 当前未开启 IPv6，不使用。 |
| 3 GeoIP_cn | 下载 Country.mmdb；当前配置没有 GEOIP 引用，不使用。 |
| 4 GeoSite | 下载 GeoSite.dat；当前配置没有 GEOSITE 引用，不使用。 |
| 5 MRS 常用包 | 包含 cn.mrs 和其他分类。mihomo 当前只引用 /data/ShellCrash/ruleset/cn.mrs；整包不是必需。 |
| 6 SRS 常用包 | sing-box 格式。当前 mihomo 不读取；切回 sing-box 时使用 cn.srs。 |
| 8 自定义 | 文件格式、路径和规则引用必须一致，下载成功并不代表生效。 |
| 9 清理 | 会删除当前引用的域名库，可能导致服务启动失败。不是清理运行日志。 |

国内域名库用于国内直连、国内 DNS 和 Mix 模式的真实地址例外。国内 IP 网段用于流量分流，两者互补。当前 mihomo 的 geo-auto-update 为 false，文件由部署和显式维护管理，不会自动下载全部 Geo 数据库。

规则页的“更新国内 IP 规则”只更新 IPv4 网段。域名库目前是固化版本，该按钮不会更新它。不要把它理解为“更新全部数据库”。

2026-10-09 核对官方 ShellCrash update 分支的 mrs.tar.gz：含 cn.mrs，也含 cnip、proxy、games 等其他分类。整包约 0.9 MB 压缩后，安装还需要解压空间；本次 AX5 剩余闪存约 488 KB，不建议直接安装整包，更不能安装约 5 MB 的完整 GeoSite。

## 完整 GeoSite 与空间评估

本轮读取工具源的完整 geosite.dat，文件约 4.1 MB；本机 /data 余量约 488 KB。历史持久化日志约 1 MB，Entware locale-archive 约 2.8 MB，后者需要确认使用情况，不能连带删除 ZeroTier 依赖的 libc / libcrypto。UBIFS 有压缩，文件逻辑大小不等于删除后能释放的实际空间。

即使腾出文件空间，完整 GeoSite 仍有解码及索引内存开销。当前只有国内域名直连这一分类，完整分类库不是必需；本轮保留 cn.mrs，没有更换或删除有效规则。

面板可调用 ShellCrash 的 get_bin 来取得数据库，但需要独立适配：只选择当前引用的文件，空间预检，配置校验，原子替换，失败回退，成功同步镜像，并展示对应版本。直接启动交互数据库菜单或解压整包不等于安全的网页更新接口。本版 IP 更新按钮仍只处理 IPv4；域名数据库按钮尚未实现。

## 两个内核的格式区别

mihomo 使用 MRS 规则集，也可按其配置使用 GeoIP / GeoSite；sing-box 使用 SRS 规则集。不能只把扩展名改掉。两个现有国内域名文件均已保留，切换内核时引用对应格式；IP 文本网段会分别生成适配配置。格式不同并不必然改变分流意图，但两个文件的来源、日期和内容可能不同，分类不能宣称逐条一致。
