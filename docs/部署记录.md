# 安装与更新

先了解依赖：本项目需要 [ShellCrash 官方工具](https://github.com/juewuy/ShellCrash)。公开包附带未改动的 1.9.4release 原始安装包及 AX5 适配补丁；自动安装先部署工具，再接入面板。

适用 Redmi AX5 / RA67 原厂 1.0.105、已解锁 SSH、root 用户。需要 Lua/cjson、LuCI、procd、iptables、openssl 和 curl。默认管理地址为 `192.168.31.1`，改过地址则用自己的地址。

## 自动安装

在路由器 SSH 中执行：

```sh
curl -fsSL https://raw.githubusercontent.com/wcbspp/ax5-shellcrash-panel/main/bootstrap.sh -o /tmp/ax5-panel-install.sh
sh /tmp/ax5-panel-install.sh
```

脚本下载 v1.0.0 并校验 SHA256，随后自动判断安装或更新。首次安装需至少 16 MB 可用 /data 空间、256 KB overlay、24 MB 可用内存。内核使用固定提交及 SHA256 验证的官方工具源 ARMv7 sing-box 1.12.13，不执行未知最新版本。

首次安装为真实 DNS、全直连。登录小米管理页，点击 ShellCrash → 配置，填写自己的订阅；完成后选择节点和 DNS 模式。不会修改 DHCP 和网关，客户端需要按实际拓扑使用本设备的网关／DNS 才会经过它。

## 手动安装

从 [Release](https://github.com/wcbspp/ax5-shellcrash-panel/releases/tag/v1.0.0) 下载 `.tar.gz` 与 SHA256SUMS，在电脑上校验后上传路由器。解压进入目录：

```sh
sh install.sh --check
sh install.sh --install
```

预检不会安装或启动服务；首次安装拒绝覆盖已有 ShellCrash。

已安装本项目的设备执行：

```sh
sh install.sh --update
```

仅更新页面和适配源码，保留 configs、cache、ruleset 及 ZeroTier，不重启当前代理。更新前的源码备份为 `/data/ShellCrash/cache/panel-previous.tar.gz`，安装失败会尝试恢复。

## 已有其他 ShellCrash 部署

为了保护当前订阅、规则和启动方式，自动脚本不会直接接管未经本项目适配的部署。先保存完整目录、配置、内核包与启动设置，再安排迁移；不要删除目录后把它误当首次安装。当前没有提供针对任意旧部署的自动迁移承诺。

## 文件位置

| 用途 | 路径 |
| --- | --- |
| 官方工具及适配补丁结果 | /data/ShellCrash-tool/ |
| 命令入口 | /usr/bin/crash |
| 面板与设备适配 | /data/ShellCrash/ui/、ax5/ |
| 订阅、DNS、规则、内存设置 | /data/ShellCrash/configs/ |
| 内核包和版本、SHA256 清单 | /data/ShellCrash/cache/ |
| 国内域名数据库 | /data/ShellCrash/ruleset/cn.srs、cn.mrs |
| 解压内核、任务、临时日志和趋势 | /tmp/ShellCrash/ |
| 服务 | /etc/init.d/shellcrash |
| 小米菜单 | /usr/lib/lua/luci/view/web/inc/header.htm |

开机优先使用本地内核包，失败再取镜像和工具源；配置独立持久保存。镜像可选，详见[镜像接收器](镜像接收器.md)。

Mixbox 和 Entware 是独立的可选组件，并非面板依赖。[安装来源与挂载修复](Mixbox与ZeroTier.md) · [数据库](数据库与规则.md) · [验证记录](验证记录.md)
