# 安装与更新

适用 Redmi AX5 / RA67 原厂开发版 1.0.105，需要已解锁 SSH、安装 ShellCrash 1.9.4release。小米默认管理地址为 `192.168.31.1`；修改过地址的设备用自己的地址。

## 已部署设备更新面板

1. 下载 Release 源码包并解压。
2. 将 `ax5/`、`ui/` 覆盖到路由器 `/data/ShellCrash/`。保留原来的 `configs/`、`cache/`、`ruleset/`。
3. 同步下面三个入口，设置脚本权限，然后刷新浏览器。仅更新页面不需要重启代理。

| 源码文件 | 路由器位置 |
| --- | --- |
| ax5/controller.lua | /usr/lib/lua/luci/controller/web/shellcrash.lua |
| ax5/view.htm | /usr/lib/lua/luci/view/web/shellcrash.htm |
| ax5/shellcrash.init | /etc/init.d/shellcrash |

```sh
chmod 755 /data/ShellCrash/ax5/*.sh /etc/init.d/shellcrash
```

## 首次部署

公开包是适配源码，首次安装还要准备自己的代理配置和 ARMv7 内核包，不能只复制源码后直接启动。需要 Lua/cjson、LuCI、procd、iptables、openssl 和 curl。

| 运行文件 | 位置 |
| --- | --- |
| 订阅转换后的基础配置 | /data/ShellCrash/configs/config.json |
| 启用标记 | /data/ShellCrash/configs/enabled |
| 当前内核类型、版本、SHA256、固定来源清单 | /data/ShellCrash/cache/core.env |
| 与清单哈希相符的内核包 | /data/ShellCrash/cache/core-armv7.tar.gz |
| 国内域名规则集 | /data/ShellCrash/ruleset/cn.srs、cn.mrs |
| ShellCrash 官方工具及本项目适配补丁 | /data/ShellCrash-tool/、tool-patches/ |

基础配置按 sing-box JSON 保存，mihomo 配置由适配层生成。`tool-patches/` 对应上游 1.9.4release，不能用于任意工具版本。现有服务应先备份，再按本项目目录表完成适配；公开包没有私人订阅、密码、内核包或设备身份。

完成适配后执行 `/etc/init.d/shellcrash enable`、`/etc/init.d/shellcrash start`。在路由器管理页点击 **ShellCrash**，沿用路由器登录，无需单独面板密码。网页处理订阅、节点、DNS、规则、启停和日志，终端执行 `crash` 打开工具菜单。

## 其他说明

- 默认启动优先本地内核包，失败再用自定义镜像和工具源；更新不会覆盖订阅配置。
- 镜像可选，配置方法见[镜像接收器](镜像接收器.md)。网页内核切换可能需要镜像保存旧版本，用于空间不足时回退。
- 只安装面板不会改变网关或 DHCP。客户端要经过这台设备，需要按自己的网络设置网关和 DNS。
- Mixbox 和 Entware 安装来源见[安装与修复说明](Mixbox与ZeroTier.md)。
- ZeroTier 修复脚本为 `zerotier/zerotier.sh`，安装到 Mixbox 同名脚本位置；合并 local.conf 设置时保留原有身份和网络配置，不要直接覆盖数据目录。

数据库说明见[数据库与规则](数据库与规则.md)，详细兼容性与测试过程见[验证记录](验证记录.md)。
