# 镜像接收器部署

cloud/receive.py 是受限 SSH 上传接收器，需按服务器目录结构调整文件中的两个 base 路径。公网目录只放按哈希命名的 core、cn 和 info；backup 必须放在独立私有目录，禁止 HTTP 访问。

为上传账号创建这些目录并设置权限，再安装接收器。该账号的 authorized_keys 使用独立上传公钥，限制为 forced command，禁用端口转发、PTY、agent forwarding 和 X11。不要给路由器配置服务器 root 密钥。

Nginx/OpenResty 的只读下载规则必须允许 core-<64位SHA256>.tar.gz、cn-<64位SHA256>.mrs、info-<64位SHA256>.txt，以及 meta-info.txt / singbox-info.txt。版本指针响应加 Cache-Control: no-store；禁止目录索引和 dot 文件访问。修改后先执行配置检查，再 graceful reload。

面板填写该对象目录的 HTTP(S) 地址和上传账号 SSH 目标。首次部署需通过其他可信渠道核对服务器主机公钥，写入路由器 configs/mirror_known_hosts；不能把“自动接受未知主机公钥”当成默认方案。私钥保存在 configs/mirror.key，权限 600。

接收器仅接受 put <类型> <SHA256> <扩展名>，限大小、校验内容，原子发布。info 还要求对应 core 文件已存在。路由器上传后通过 HTTP 流式读回公开对象验证；私人备份只经 SSH 校验。
