# 测试记录

测试日期：2026-10-09 至 2026-10-10。设备：Redmi AX5 / RA67，原厂开发版 1.0.105，Linux 4.4.60，ARMv7。

## 功能测试

| 项目 | 结果 |
| --- | --- |
| 路由器登录与操作鉴权 | 沿用小米登录会话，无效 CSRF 请求被拒绝 |
| 订阅直接下载 | ShellCrash 原生获取、解析和加载通过；实际导入 146 节点 |
| 协议兼容 | 101 AnyTLS、45 SS + HTTP 混淆；3 个兼容旧节点 HTTPS 检测通过 |
| 转换服务 | 第一项预检失败时未发送订阅；第二、第三项分别完成转换及加载 |
| 错误保护 | 下载、配置校验或启动失败保留或恢复原配置 |
| 内核切换 | sing-box 1.12.13 / Mihomo v1.19.28 切换与配置校验通过 |
| DNS | Google 返回 Fake IP；百度、OpenAI、STUN、Apple、小米例外返回真实地址 |
| 分流 | 国内域名命中国内域名库，国内 IP 命中网段直连；Google 经所选代理 |
| 重启 | 代理、本地内核恢复、Entware 挂载和 ZeroTier 恢复 |
| 启动与守护 | 自启动与工具设置同步；系统 procd 和每分钟检测切换后均只有一个代理服务 |
| 手动停止 | 停止后不被每分钟检测拉起 |
| 内存管理 | 清理、阈值保存、状态刷新、日志大小限制和趋势采样通过 |
| 页面 | 节点、配置、DNS、监控与日志操作通过 |
| SSH | 连续 10 次新连接未复现首次连接退出 |

实际订阅中 45 个原始 SSR 链接使用 origin/http_simple。服务商按客户端标识返回兼容 Shadowsocks 格式，面板保留 HTTP 混淆参数。三项 HTTPS 延迟检测为 606、425、456 ms。该结果不代表 sing-box 支持任意原生 SSR。

## 自动检查

- Python：10 项恢复与订阅适配检查。
- JavaScript：5 项实际解析器协议检查。
- Lua：10 项守护检查、5 项守护切换检查、3 项 Mihomo 协议转换检查。
- 页面脚本语法与源码差异格式检查通过。

## 测试边界

首次安装模板通过 ARMv7 sing-box 配置校验，安装更新流程在已有设备上执行通过；未清空测试设备进行完整全新安装。

工具正式版更新测试包含同版不替换、离线版本替换和失败回退。测试时官方正式版为 1.9.4release，未在实机安装尚不存在的新正式版本。

短期内存采样及重启测试通过，不能代替长期高负载测试。节点延迟受线路、握手和服务商影响；接口检测正常也不保证所有网站、流媒体和游戏可用。

其他固件、型号和任意 ShellCrash 旧部署迁移未验证。
