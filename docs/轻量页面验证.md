# 轻量页面验证记录 · 2026-10-10

首页保留当前节点、运行内核和时长、连接数、内存、异常计数、开机启动和实际守护。启动来源移到配置页；内核与工具更新、镜像与备份、国内数据库维护分别收纳在对应页面的展开项中。

规则页新增只读查询：查看内核实际加载的规则、策略组和当前连接，支持筛选及每页 20 条。只在进入页面或手动查询时读取，离开或隐藏页面取消请求并释放浏览器缓存；没有新增常驻进程或轮询任务。

AX5 对规则和连接逐条解析，最多暂存 1 MiB 响应、单条最多 16 KiB；串行查询，更新任务进行中、内核停止或内存低于保护阈值加 4 MiB 时拒绝查询。临时文件与锁在结束时清除。K2P 使用现有内核接口，当前视图缓存在浏览器，离开即释放。

## 验证结果

- AX5 浏览器验证：4313 条规则的首/次页、RuleSet 筛选、34 个策略组、活动连接查询、查询时切离页面；节点页正常恢复。
- AX5 Lua 验证：分页、过滤、跨读取块与转义字符、超大单条拒绝、低内存/停止/并发拒绝、查询失败及凭据不回传。
- K2P 实机 sing-box `/rules` 返回 7 条规则，前端归一化成功，包含 cn 国内域名规则。
- 离线检查：AX5 10 项 Python 测试、K2P 67 项 Python 测试，两端各 5 项协议解析测试与 JavaScript 语法检查通过。
- AX5 规则逐条解析基准：4313 条，返回 20 条；约 2.52 秒 CPU 时间，查询前后可用内存约 28/27 MiB。这是前后采样，不代表峰值。
- 部署与检查没有重启内核；两端进程保持，异常恢复计数均为 0。K2P 最终文件已写入 Storage。
