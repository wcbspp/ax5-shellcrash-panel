只更新官方 stable 正式版。同版本不替换；保留配置、面板与适配，兼容校验不通过则保留旧版。工具更新不重启代理或其他服务。

代理内核

sing-box mini

调用 ShellCrash 适配源，校验通过后替换本地内核包，再同步镜像。失败恢复旧版；闪存只容纳一个内核包时，替换前须确认旧版可回退。开机不查询新版本。工具索引可能高于 mini 包实际版本，运行版本以安装校验为准。

自定义镜像

启动先用已安装版本的本地包，缺失或损坏时按镜像、工具公网源顺序恢复，并验证哈希。镜像查询仅在手动检查时进行。更新后的云端同步结果独立显示，可手动重试；SSH 上传需部署密钥。

国内 IP 白名单

更新当前内核的国内 IP 分流规则，校验后保存到路由器。应用时代理短暂重启；下载或校验失败保留旧规则。规则相同则无需重启。

已内置国内 IP 默认表，保存在 /data/ShellCrash/configs；重启沿用本地规则。手动更新源：ispip.clang.cn（IPv4）
国内域名使用本机固化的 cn.srs（sing-box）或 cn.mrs（mihomo）；此 IP 按钮不修改域名库，域名库使用下方独立按钮更新。mihomo 引用 cn.mrs；sing-box 引用 cn.srs，未使用 GeoSite.dat 或 Country.mmdb。DNS 模式与例外名单在“DNS”页设置；节点在“配置”页更新。

国内域名数据库

调用 ShellCrash 数据库源，只提取当前内核使用的 cn.mrs 或 cn.srs。校验后替换，失败恢复旧库；内容相同不重启。应用新库时代理短暂停止，成功后备份到镜像私有目录。

ShellCrash 数据库菜单怎么选？

CN-IP：工具下载的 cn_ip.txt 不会自动改写本面板配置，请用上面的 IP 更新按钮。CN-IPv6：当前关闭 IPv6，暂未使用。

GeoIP_cn / GeoSite：当前配置没有引用，无需安装。MRS 常用包包含正在使用的 cn.mrs，也包含其他未引用的库；闪存紧张时请勿整包安装。SRS 是 sing-box 格式，mihomo 不读取。

自定义数据库需要匹配格式、文件路径及规则引用。清理数据库会删除当前使用的域名库，可能造成启动失败，请勿作为普通日志清理。

Mix 对国内域名返回真实地址，对其他域名返回 198.18.x.x 虚拟地址；例外名单返回真实地址。两种模式都继续按同一分流规则决定直连或代理。

名单内返回真实地址，流量仍按分流规则决定。每行一项；支持域名、*.、+. 和 # 注释；最多 512 项。Mijia Cloud 使用小米生态域名替代。保存时代理短暂重启。

保存后路由器按新名单回答 A 查询；客户端已有 DNS 缓存需刷新。当前关闭 IPv6，AAAA 不返回 IPv6 地址。

普通 UDP 保持直连；指向 Fake IP 的 UDP 被拒绝以便回落 TCP。游戏、STUN 等需在例外名单中。
